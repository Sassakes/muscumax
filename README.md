# Muscumax · ROUND

Carnet de musculation personnel, pensé pour le MMA et l’iPhone.

## Vercel

Importez ce dépôt dans Vercel. Framework : Vite. Build : `npm run build`. Dossier de sortie : `dist`. Aucune variable d’environnement requise.

## Local

Node.js 22.18+ : `npm install`, puis `npm run dev`.

## Fonctions

- Deux séances essentielles et une full body facultative.
- Charges, séries, répétitions et marge en réserve.
- Reprise de séance, minuteur, historique et progression.
- Mode fatigue MMA, export/import JSON.
- Installation iPhone et cache hors connexion après un premier chargement complet sur HTTPS.

Les données restent sur l’appareil. Exportez régulièrement votre carnet.
